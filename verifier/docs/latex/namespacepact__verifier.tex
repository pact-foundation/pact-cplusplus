\doxysubsection{Detailed Description}
Minimal, dependency-\/free HTTP/\+1.\+1 server used to host the provider state change endpoint required by Pact verification.

It is deliberately small (single connection at a time, {\ttfamily Connection: close}) because the Pact verifier drives the provider sequentially. It is also useful for standing up a stub provider in your own tests, but it is not intended to be a general purpose production web server.
