\doxysubsection{Detailed Description}
Parameters supplied with a provider state, as defined by the consumer with {\ttfamily given(state, params)}.

Values are exposed as strings. JSON strings are unquoted; any other JSON value (numbers, booleans, objects, arrays) is returned as its raw JSON text. Use \doxylink{verifier_8cpp_ab701e3ac61a85b337ec5c1abaad6742d}{json()} if you need the untouched document.
